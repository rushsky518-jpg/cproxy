路由

服务名 公开路径前缀 本地目标 去前缀 状态

前缀必须与前端 base 一致（本项目为 /higobase-admin），多条路由的前缀不能重叠。

三步共享本地站点

  1. 本地启动带 base 的站点：npm run dev -- --base=/higobase-admin/ --port 5174 --strictPort
  2. 把目标地址填成 127.0.0.1:5174，路径前缀填 /higobase-admin。
  3. 点“保存并生效”：路由立即在公网服务器上更新，同时写回配置文件，无需重启 agent。
